# Summary of this project
This project integrates YOLOv5 object detection with DeepSORT multi-object tracking to perform real-time identification and tracking of vehicles (cars, buses, motorcycles, trucks) in intersection video feeds. 
It counts each vehicle type’s passages within predefined statistical zones and detection lines, compares experimental error rates, analyzes how model and environmental settings affect counting accuracy. Finally it shows high accuracy and increase the traffic of the crossing in a section time.
